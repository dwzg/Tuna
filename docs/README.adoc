= Tuna documentation

This directory holds the project's reference documentation, written in
https://asciidoc.org/[AsciiDoc]. The master document is `index.adoc`, which
`include::`s the chapters below.

== Contents

[cols="1,3",options="header"]
|===
| File | Chapter

| `index.adoc`             | Master document (book): title, abstract, includes.
| `overview.adoc`          | What Tuna is, design goals, end-to-end data flow.
| `hardware.adoc`          | Target MCU, acquisition path, display wiring.
| `building.adoc`          | Toolchain, CMake build, flashing, CI.
| `architecture.adoc`      | State machine, acquisition pipeline, layering.
| `signal-processing.adoc` | Silence gating, YIN, FFT, windows, note mapping, smoothing.
| `display.adoc`           | Framebuffer, 7-segment/bar-graph renderers, MAX7219 driver.
| `configuration.adoc`     | Every `config.h` macro and build-time override.
| `module-reference.adoc`  | Per-module quick reference and dependency map.
| `testing.adoc`           | Host regression-test suite and how CI uses it.
| `glossary.adoc`          | Terms and abbreviations.
|===

== Building the docs

With https://asciidoctor.org/[Asciidoctor] installed:

[source,sh]
----
# Single-page HTML
asciidoctor docs/index.adoc -o docs/tuna.html

# PDF (requires asciidoctor-pdf)
asciidoctor-pdf docs/index.adoc -o docs/tuna.pdf
----

The chapter files are meant to be read through `index.adoc`; opening them
individually still works but cross-references and numbering come from the master.
