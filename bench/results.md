# Tuna compiler-optimization benchmark

_Generated by `bench/run_bench.sh`._

- **Flash / RAM**: real firmware built for `avr64dd14` (7.3.0 avr-gcc), measured with `avr-size`. Exact for the target.
  Flash = text+data, RAM = data+bss.
- **DSP cycles**: one pitch pass over a fixed 220 Hz frame, counted under simavr on
  `atmega1284p` (classic AVRe+ core -- simavr has no AVR-Dx core). Relative proxy, not absolute Dx timing.
- **Frame budget**: 6000000 cycles (250 ms @ 24 MHz). A method must finish a frame within this to keep up with acquisition.
- Shipped config (`CMakeLists.txt`): `Os+lto` (`-Os -flto`).
